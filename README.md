# Phần 1: Bảng so sánh
Tiêu chí	Copy bảng Excel 50 hàng	Dùng Bar Chart có highlight
Tính thuyết phục	Thấp (quá tải thông tin, gây nghi ngờ).	Cao (biến dữ liệu thô thành bằng chứng trực quan).
Tốc độ hiểu	Chậm (>30 giây, gây "Death by PowerPoint").	Cực nhanh (<5 giây để nắm bắt thông điệp).
# Phần 2: Giải pháp thiết kế Slide mới
Tiêu đề (Assertion Title): Dùng câu khẳng định kết quả, ví dụ: Doanh thu tăng trưởng 150% nhờ dòng sản phẩm chủ lực.

Biểu đồ & Màu sắc: Dùng Bar/Column Chart; dùng màu trung tính cho dữ liệu thường và 1 màu nổi bật để highlight cột quan trọng.

Cỡ font tối thiểu: Áp dụng từ 30pt trở lên theo quy tắc 30 để đảm bảo dễ đọc từ xa.
